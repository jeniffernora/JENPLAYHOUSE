1. Upload/import Jeniffer-Nora-CMS-V7-UPDATES.xlsx into Google Sheets.
2. Put the Sheet ID into Code.gs.
3. Create a Google Drive folder for Updates media and put its folder ID into Code.gs.
4. Deploy Apps Script as a Web App.
5. Paste the Web App URL into js/config.js -> appsScriptUrl.
6. Fill the Email column in the Users sheet for Jeniffer and each J-Team member.

Important: the starter login is email allow-list based. Do not put passwords in GitHub or plaintext in the Sheet.
